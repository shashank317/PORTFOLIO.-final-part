# Shashank H — Portfolio

A high-performance personal portfolio and engineering showcase for **Shashank H**, Python Backend Engineer and AI Developer based in Bengaluru, India.

Built with modern web technologies featuring custom WebGL shaders, responsive scrollytelling, kinetic typography, and fluid micro-interactions.

---

## ⚡ Tech Stack & Architecture

- **Core Framework**: [TanStack Start](https://tanstack.com/start) & [TanStack Router](https://tanstack.com/router)
- **UI Library**: React 19 + TypeScript
- **Styling**: Tailwind CSS + Custom Design System tokens
- **Animations & Graphics**: GSAP (ScrollTrigger / Timeline) + OGL (WebGL custom specular shaders)
- **State & Data**: TanStack Query + TypeScript type safety

---

## 🛠 Featured Engineering Projects

- **Parametric CAD Automation**: Automated CAD design generation pipeline using Python and FastAPI, reducing part design turnaround time.
- **AI Drawing Reviewer**: Hybrid extraction and RAG validation pipeline for automated engineering drawing inspection.
- **AI Resume Enhancer**: Resume analysis and optimization platform leveraging Gemini API with structured AST-level feedback.
- **TeamSync**: Real-time collaborative workspace management platform.
- **WhatsApp Gita AI**: Context-aware conversational AI assistant integrated with WhatsApp messaging APIs.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18+ recommended)
- `npm` or `pnpm`

### Installation

```bash
# Clone the repository
git clone https://github.com/shashank317/PORTFOLIO.-final-part.git

# Navigate into project directory
cd "PORTFOLIO.-final-part"

# Install dependencies
npm install

# Start local development server
npm run dev
```

The application will start locally at `http://localhost:5173`.

### Production Build

```bash
# Build production bundle
npm run build

# Preview production build
npm run preview
```
